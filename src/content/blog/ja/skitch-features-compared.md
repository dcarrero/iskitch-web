2011年2月、Evernoteに買収される数か月前のskitch.comには、アプリでできることを並べたページがありました。[Internet Archiveに今も残っています](https://web.archive.org/web/20110216205611/http://skitch.com/features)。2011年2月16日の記録で、広告まで含めてそのままです。

その一覧を一行ずつ、今日出荷しているiSkitchと突き合わせました。作り直したものもあれば、こちらのほうが上のものもあります。そして、あえて作らなかった一群があります。最後の点は説明が必要でしょう。

## 機能一覧の前に目につく3つのこと

**Skitchの半分はアプリではありませんでした。** ページの各項目には `Mac` か `Web` の印が付いていて、Web側のほうが多いのです。Skitchとは、プロフィールとフォロワーとコメントスレッドを備えた画像共有サイトに、Macアプリがくっついたものでした。

**無料版には広告がありました。** 「広告なしの体験」が有料の項目だったのです。Skitch Plusは**年額14.95ドル**、「期間限定、通常は19.95ドル」という但し書き付きでした。

**フッターにはカウンターが回っていました。** *保存画像 3,753,447枚、なお増加中。*

## 撮る

| Skitch（2011年） | iSkitch | 備考 |
|---|---|---|
| スクリーンショットの撮影 | あり | 範囲・ウインドウ・全画面を ⌥⌘4 / ⌥⌘5 / ⌥⌘3 で。ショートカットは変更可能 |
| iSightからの撮影 | なし | Photo Boothのほうが得意です |
| 撮影と編集の自動アーカイブ | 一部 | フォルダへの直接保存はできますが、一覧できる履歴はまだありません |
| ブックマークレットによるWebキャプチャ | なし | 2011年の時点で「Coming soon!」と書かれていました |
| Webページ全体の撮影 | なし | 検討中です |

当時のページになかったもの。カウントダウンタイマー、直前の範囲をもう一度撮る機能、モニタが3台あるときにどれを撮るかの選択、エディタを開かずにクリップボードへ送る撮影。いずれも今のiSkitchにあります。

## 編集する

| Skitch（2011年） | iSkitch | 備考 |
|---|---|---|
| 内枠をドラッグしてトリミング | あり | 1:1、4:3、3:4、16:9、9:16の比率つき |
| テキスト、矢印、図形、手描き、Wacomタブレット | あり | 14種類のツール、4種類の矢じり、7種類のスタンプ |
| タグとセットによる整理 | なし | それはWebサイト側の機能でした |
| 透かしの追加 | なし | 検討中です |
| tif、gif、bmp、svg、pdfで保存 | 一部 | PNG、JPG、TIFF、PDF。GIFとBMPとSVGはありません |
| 影、背景の透過、撮影部分以外の消去 | なし | 検討中です |
| 数値やプリセットでのサイズ変更 | なし | 25〜300%の表示倍率はありますが、画素そのものは変わりません |

逆に、iSkitchにあって2011年の一覧に出てこないもの。**機密情報を隠す4つの方法**（モザイク、ぼかし、塗りつぶし、斜線）、伝えたい箇所以外を暗くする**スポットライト**、ステッカー、画像の重ね貼り、コラージュ、回転と反転、そして**18言語**のインターフェイスです。

## 共有 — ここは意図的に道を分けました

元の一覧には、共有とソーシャルの機能が11個ありました。無料の画像ホスティング、ブログのような公開プロフィール、フォロワー、公開範囲の設定、FlickrやMobileMeへのアップロード、300枚を並べるダッシュボード、そして「強力なビジュアルコメントスレッド」。

iSkitchにはそのどれもありません。これからも入れません。あるのはmacOSの共有シート、どのアプリへでもドラッグして渡すこと、コピー、書き出しだけです。自分で送らないかぎり、Macから何も出ていきません。

理由は実験してみるとわかります。今日ブラウザに `skitch.com/だれか/なにか` と入れると、たどり着くのは**evernote.com**です。今朝、実際に確かめました。誰かがバグ管理ツールやフォーラムやサポートの問い合わせに貼ったSkitchのリンクは、いま企業のトップページを指しています。あの370万枚の画像は、事実上もう存在しません。

自分のディスクにあるPNGは、15年後でも開きます。懐古趣味の話ではなく、iSkitchにアカウントもサーバーもログインもない理由そのものです。

## Evernote時代のSkitchが足したもの

2011年のページは、多くの人が覚えている道具立てよりも前のものです。のちのバージョンで、承認や却下に使う**スタンプ**、**モザイク**、**マーカー**が加わりました。3つともiSkitchにあります。スタンプは7種類で、色の円板の上に記号が乗り、指したい方向へしっぽを伸ばせて、横に文字を添えられます。

こちらに足りないのは**PDFへの書き込み**です。Skitch 2.5で登場し、30日を過ぎるとPremiumアカウントを求められました。私たちのものなら、アカウントは要りません。これも一覧に入っています。

## まだ足りないもの

正直なところを、まとめて置いておきます。

- 画像を指定サイズに変更する
- 影と背景の透過
- 透かし
- GIFとBMPでの書き出し
- Webページ全体の撮影
- PDFへの書き込み
- 過去の撮影を見返せる履歴

この一覧は隠している願望リストではなく、そのまま私たちのバックログです。どれか1つが乗り換えの障害になっているなら、教えてください。**hello@iskitch.com** です。直近の3つのバージョンは、Skitchを実際に使っていた方々の要望で形が決まりました。

## 15年後に

2008年の時点で、Skitchは大事な半分を言い当てていました。何かを撮り、矢印を1本置いて、数秒で相手の目の前に届ける。間違えたのは、その半分を他人が動かし続けなければならないサービスに結びつけたことです。

[iSkitch](/) はその前半を、Apple Siliconネイティブで作り直したものです。18言語、買い切り。後半はあなた自身のディスクが担います。
